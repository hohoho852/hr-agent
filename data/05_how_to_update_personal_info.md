# How to Update Personal Information (Employee Guide)

**Audience:** Employees  
**System path:** People Portal / company HR system → Personal Information / Employee Profile  
**Policy source:** `04_personal_data_and_profile_policy.md`

---

## Goal

Correct your address, phone, emergency contact, or other allowed personal fields without waiting for HR on routine updates.

## Steps — update address or phone

1. Sign in to the **People Portal** (company HR system).  
2. Click your **name / photo** (top right) → **Show profile** / **Personal Information**.  
   - Alternate: search **“Personal Information”** or open **Employee File**.  
3. Find the section:
   - **Contact Information** (phone, email)  
   - **Addresses** (home address)  
4. Click the **pencil / Edit** icon.  
5. Enter the new values.  
6. Set **Effective as of** date (when the change should apply).  
7. **Save**.  
8. If a workflow appears, submit for approval (some tenants route address changes to HR).

## Steps — emergency contact

1. Open **Personal Information** → **Emergency Contact**.  
2. **Add** or **Edit** contact.  
3. Enter name, relationship, phone.  
4. Mark **primary** if required.  
5. **Save**.

## Steps — bank details (salary)

> Only if self-service bank edit is enabled in your tenant.

1. Open **Payment Information** (or **Bank Information**) from Employee File.  
2. Click **Edit**.  
3. Enter bank name, account name, account number, and any local clearing code.  
4. Set effective date **before next payroll cut-off** (see payroll calendar on People Portal).  
5. **Save** and complete any verification challenge.  
6. Confirm a success message. If the section is **view-only**, open an **HR ticket** with proof of account (mask middle digits in chat).

## What you cannot change yourself

| Field | Action |
|-------|--------|
| Legal name | HR ticket + legal proof |
| HKID / passport | HR ticket + document scan via secure upload link |
| Department / manager / title | Not employee self-service |
| Base salary | Compensation process only |

## After saving

- Most contact changes show immediately on your profile.  
- Payroll-impacting changes apply from the **effective date** and next successful payroll run.  
- Download or screenshot confirmation if you need evidence.

## Common issues

| Issue | What to do |
|-------|------------|
| No Edit pencil | Field is HR-secured → ticket HR |
| Save error / required field | Complete country-specific address fields (e.g. district) |
| Wrong effective date | Edit again or contact HR if locked |
| Still seeing old phone | Hard refresh / wait sync; else HR |

## Guardrails for AI answers

- Give these steps.  
- Warn not to paste full bank/HKID into the assistant.  
- Do not claim the update already posted to payroll.  
- Escalate legal identity changes to HR — do not invent a self-service path.
