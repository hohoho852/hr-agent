# How to Request Time Off in SuccessFactors (Employee Guide — Demo)

**Audience:** Employees  
**System path:** SuccessFactors → Time Off  
**Policy source:** `02_leave_and_time_off_policy.md`

---

## Goal

Submit annual leave, sick leave, or other absence so your manager can approve it and your balance updates correctly.

## Before you start

1. Check the **Leave and Time Off Policy** for notice periods and documents.  
2. Confirm you are not in a published **blackout** period (or accept manager may decline).  
3. For sick leave ≥2 consecutive days, prepare a **medical certificate** scan/photo.  
4. Do not share full medical details in the comment field — “medical cert attached” is enough.

## Steps — desktop (Employee Central / Time Off)

1. Sign in to **SAP SuccessFactors**.  
2. Open the **home** page and select **Time Off** (or search “Time Off” in the global search).  
3. Choose **Request Time Off** (or **New Absence**).  
4. Select **Time Type** (e.g. Annual Leave, Sick Leave).  
5. Enter **start date** and **end date**.  
   - For half-day: enable half-day and choose AM or PM if available.  
6. Review the **deduction preview** / balance impact shown by the system.  
7. Add an optional **comment** for your manager (reason at high level only).  
8. **Attach** medical certificate or other required file if applicable.  
9. Click **Submit**.  
10. Status becomes **Pending** until your manager acts.

## Steps — mobile (SuccessFactors mobile app)

1. Open the app and sign in.  
2. Tap **Time Off** / **Absences**.  
3. Tap **+** or **Request**.  
4. Select type, dates, half-day if needed.  
5. Attach file if required → **Submit**.

## After submit

| Status | Meaning | What you do |
|--------|---------|-------------|
| Pending | Waiting on manager | Wait; optional polite reminder after SLA |
| Approved | Counted against balance | Take leave as planned |
| Declined | Not approved | Read comment; resubmit or discuss offline |
| Cancelled | You or admin cancelled | Rebook if still needed |

### Cancel or edit

1. Open **Time Off** → **My Requests**.  
2. Select the request.  
3. **Withdraw/Cancel** if still pending or if policy allows cancel after approval (manager may need to re-approve changes).  
4. To change dates, cancel and create a **new** request unless edit is enabled for your tenant.

## Manager SLA (internal target)

Managers should action routine leave within **2 working days**. Escalation: ping manager once, then HRBP if blocked before travel.

## Common errors

| Symptom | Likely cause | Fix |
|---------|--------------|-----|
| Cannot submit | Missing mandatory field / attachment | Complete required fields |
| Wrong balance | Pending older request | Check pending items first |
| Type greyed out | Not eligible / not hired fully | Contact HR |
| Overlap error | Existing absence same days | Edit/cancel prior request |

## Related questions employees ask

- “How many AL days do I get?” → see Leave policy entitlement table.  
- “Can I carry leave?” → up to 5 days, use by 31 March.  
- “Do I need a doctor note?” → yes for 2+ consecutive sick days.

## Guardrails for AI answers

- Never claim a specific person’s remaining balance.  
- Never submit the request on the employee’s behalf.
