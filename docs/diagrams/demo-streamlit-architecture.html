What this demo proves

  • Employees ask policy / HR how-to questions and get cited answers from the handbook pack.
  • Handbook text is embedded on the app host (local BGE + Chroma); only retrieved snippets go to the LLM.
  • Generation uses a customer-chosen OpenAI-compatible model key held in Streamlit Secrets.
  • Operators can see latency, token usage, and estimated cost per request, plus a golden-question eval gate.
  • Not production: public URL, sample employer corpus, no company SSO. For private tenant deploy see the production diagram and docs/DEPLOY-GUIDE.md.
